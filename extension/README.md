# Extension Makasi AI pour Chrome & Edge 🚀

Cette extension vous permet d'ouvrir Makasi AI d'un simple clic depuis la barre d'outils de votre navigateur !

## Comment l'installer en 30 secondes :

1. Ouvrez votre navigateur (Google Chrome, Brave ou Microsoft Edge).
2. Rendez-vous sur la page des extensions :
   - Sur Chrome : `chrome://extensions`
   - Sur Edge : `edge://extensions`
3. En haut à droite, **activez le « Mode développeur »** (Developer mode).
4. Cliquez sur **« Charger le dossier non empaqueté »** (Load unpacked).
5. Sélectionnez le dossier `extension` situé dans `makasi ai/extension`.

C'est tout ! L'icône Makasi AI apparaît dans votre barre d'extensions. Cliquez dessus pour discuter avec Makasi AI à tout moment sans quitter votre page web !
